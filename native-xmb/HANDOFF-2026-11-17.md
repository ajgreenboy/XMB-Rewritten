## 1. What this is

A native C++20 / Qt 6 recreation of the PlayStation 3 firmware 4.93 XMB, used as a living-room HTPC
front end on Windows. It renders the XMB (ribbon, columns, icons, dialogs, OSK, photo gallery, music and
video players) from data traced out of the 4.93 firmware, and launches Steam, emulators and web apps from
it. The pixel target is the real console; a gate compares scripted frames against saved references.

## 2. What landed 2026-11-13 to 11-17

All merged to `main`. Release cadence was fast: `v0.3.7` … `v0.3.12` (six releases in the stretch).

- **Parity sweeps 5–8 against the real console in RPCS3** (`audit/PARITY-SWEEP-5` … `-8-RPCS3-2026-11-16.md`).
  The last four sweeps were live-console: Photo/Music/Video/Network/Game column rows, Triangle menus,
  message and confirm pages, Search for Media Servers wait/result pages, Network Remote Play help text,
  and depth-1 item page icon geometry (one open `RECORD`).
- **Jellyfin music phase 2** (`audit/JELLYFIN-MUSIC.md`): timed lyrics on Now Playing, Favourites /
  Recently Played / Most Played rows, favourite toggles, and Play / Shuffle Play on album, artist and
  playlist rows.
- **Video player control panel** (`audit/JELLYFIN-PLAYER.md` / `audit/INFO-BAR.md`): Display information
  bar, Go To, Screen Mode, an information page, and scoped audio/subtitle panels.
- **RAF (animated) themes** (`audit/RAF-THEMES.md`): a shared VSMX disassembler, GTF/Edge decode and
  usage sweep; themes still render as **one still frame, not animated**.
- **Steam** (`audit/STEAMCMD.md`): SteamCMD install/update/validate from the XMB, Steam background mode
  (hidden client start, account-switch restart), and key-free artwork from a conservative Steam store
  title match for imported games.
- **Usenet downloads** (`audit/STEAM-DOWNLOADS.md` area): SABnzbd + Seerr — recover download queues,
  control Seerr transfers through SABnzbd, preserve the reverse-proxy base URL, flush saved progress on
  stall, PS3 download icons, and game transfer pause/resume. Download Management is now a live surface.
- **Page text prewarm** (`audit/FRAME-PACING.md`): warm glyph tiles of pages opened with Cross to kill
  first-open page hitching.
- **Kiosk** (`packaging/README.md`): watchdog launched through `kiosk-launch.vbs` so no console window
  sits over the XMB on Windows 11 (a prior `conhost --headless` throttled the XMB to 0.5 fps).

## 7. Using this in a Claude Project

Upload this file plus `README.md`, `ISA.md`, `audit/README.md`, `audit/PHASES-2026-11-07.md`,
`audit/RELEASE-CHECKLIST.md`, `audit/HTPC-RUN-GUIDE.md` and `HANDOFF-2026-11-13.md`. A Project cannot

data into a Project.
